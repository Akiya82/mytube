# MyTube

[English version](README.md)

Self-hosted доставка видео для небольшой компании: прогрессивный MP4 для
плеера AVPro в VRChat и для обычного браузера, рассчитанная на одного
человека и около десятка друзей, которые смотрят синхронно. Это не соцсеть:
здесь нет комментариев, рекомендаций и рекламы.

## Сначала прочитайте три вещи

**Каждый зритель должен включить «Allow Untrusted URLs».** Это настройка
самого клиента VRChat, один раз на зрителя. Обойти её с нашей стороны
нельзя: без неё AVPro не откроет ни один адрес, который выдаёт этот сервис.

**Публичные и group-public инстансы VRChat не поддерживаются.** Начиная с
билда клиента 1546 «Allow Untrusted URLs» там не действует, а домен мира
должен быть в белом списке самого VRChat. Это ограничение платформы, а не
ошибка проекта. Приватные инстансы и инстансы для друзей работают.

**Адаптивного битрейта нет.** Разные качества — это отдельные видео с
отдельными ссылками, их выбирают при конвертации. В плеере мира VRChat нет
ручки для переключения, поэтому здесь ничего подобного не пытаются делать.

## Быстрый старт

Нужны Docker с плагином Compose и имя хоста для интерфейса.

```bash
cp .env.example .env
# заполните значения с пометкой «generate» и оба имени хоста
docker compose up -d
docker compose ps
```

По умолчанию стек тянет опубликованные образы, `ghcr.io/akiya82/mytube` и
`ghcr.io/akiya82/mytube-worker`, и монтирует локальный каталог `./share` как
исходную библиотеку. Образы собраны под amd64; на ARM-машине, например на Mac
с Apple silicon, Docker запускает их через эмуляцию: медленнее, но работает.
Это меняют два дополнительных файла:

- `docker-compose.build.yml` собирает образы из этой копии репозитория.
- `docker-compose.cifs.yml` монтирует сетевую шару вместо `./share`.

Подключайте их через `-f`, например
`docker compose -f docker-compose.yml -f docker-compose.cifs.yml up -d`.
Если стек не поднимается, `docker compose logs api` назовёт недостающую
настройку. В SETUP.md есть раздел с диагностикой по симптомам.

## Хранилище

Код говорит на чистом S3, поэтому подойдёт любой S3-совместимый адрес. Compose
поднимает SeaweedFS, потому что нужно что-то, что работает на чистой машине.
Собственная установка автора его не использует: она смотрит во внешний
MinIO. Если у вас уже есть MinIO или другое S3-хранилище, направьте на него
переменные `MYTUBE_S3_*` и не трогайте встроенное.
